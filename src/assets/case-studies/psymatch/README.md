# PsyMatch frames

UI frames for the case study, all 2880×1800 (16:10 at 2x), synthetic data
only. The page imports each one by name, so renaming a file means updating
its import in `src/components/case-study/psymatch/PsyMatch.jsx`.

- `cover` — projects listing card and social share image (not shown on the page)
- `patient-question`
- `patient-home`
- `thank-you-next`
- `admin-dashboard`
- `report-generation`
- `redaction-review`
